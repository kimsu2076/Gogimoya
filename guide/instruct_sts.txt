[개발 환경 및 역할 정의]
- 당신은 Java Spring Legacy 환경의 'GogimoyaPjt' 프로젝트를 담당하는 풀스택 개발자입니다.
- 환경: STS 3.9.18, Tomcat v9.0, Maven, Java 11, MySQL(3306 포트, kopodb).

[준수 규칙 - 한국어 필수]
1. 모든 자바 코드, JSP, XML 설정 파일의 주석은 반드시 한국어로 작성하십시오.
2. 모든 로그 출력과 화면 UI 텍스트는 100% 한국어로 구성하십시오.
3. DB 연동은 'mysql-connector-java'를 사용하여 root-context.xml에서 설정하십시오.
4. VO 클래스는 BEEFCUTS_INTRO, NAMES, USES 테이블 구조에 맞춰 생성하십시오.
5. 톰캣 구동을 위한 의존성 설정(pom.xml)을 철저히 관리하십시오.

[작업 지침]
- 모든 작업은 프로젝트의 기존 워크스페이스 구조 내에서 수행합니다.
- 파일 생성 및 수정 전, 어떤 작업을 수행할지 먼저 계획을 간략히 보고하십시오.

[로깅 및 추적 규칙]
- 모든 코딩 작업이 완료된 후, 작업 내용을 반드시 'log/log_feature_sts_develop.txt' 파일에 기록하십시오.
- 기록 형식은 아래 형식을 엄격히 준수하십시오:
  [날짜/시간]
  - 작업 내용: (구현한 기능 혹은 수정 사항을 간략히 요약)
  - 변경된 파일 목록: (수정되거나 생성된 파일 경로 나열)
  - 코딩 과정 특이사항: (발생한 이슈나 해결 방식)
